# Submitting your project

Your **code** lives in your GitLab repository; your **hand-in** goes to
**Moodle**. Read this page before you submit.

---

## What to hand in on Moodle

Upload the following to the Moodle assignment:

- [ ] **A working link to your GitLab repository** — make sure the teacher has
      access and the link opens the project.
- [ ] **A screenshot of a completed test run** — run `make test` and capture the
      results shown in the terminal / test panel.
- [ ] **Your AI usage PDF** — a single PDF (see [AI usage PDF](#ai-usage-pdf)
      below).

> ⚠️ **Deadline:** a **late submission** scores a **maximum of half the points**,
> no matter how complete it is.

---

## Your code (GitLab)

The repository stays the code submission — nothing extra needs to be committed to it.

1. Work on the `project` branch.
2. Commit regularly — at minimum one commit per class you complete. Use clear
   messages like "Implement Emoji record" or "Fix Board placement logic". The
   commit history is part of your submission.
3. Push to GitLab before the deadline.
4. The project must compile and run — `make test` must run without compilation
   errors.

---

## AI usage PDF

Hand in **one PDF** that contains **both** of the following:

**1 · Your AI usage report** — answer these questions:

- Did you use AI tools while doing this assignment? (Yes / No)
- How did you use AI tools?
- Did it help, and how did it help?

**2 · The AI prompts you used** — your prompt history during the project
(from ChatGPT, Copilot Chat, Claude, etc.), exported or pasted into the **same**
PDF.

If you used **no** AI tools, say so in the report section — then there are no
prompts to include, but you still submit the PDF with the report.

> The report answers may be used anonymously in research.

> ⚠️ A **missing AI usage PDF** caps your project score at **half the points**.

---

## A note on using AI tools

You are not prohibited from using AI tools. You might be asked to walk through
your own code line by line and explain your decisions. If you did not write it
yourself, you will not be able to answer those questions.

The safest approach is to write the code yourself, use AI to check your
understanding, and make sure you can explain every line before you submit.
